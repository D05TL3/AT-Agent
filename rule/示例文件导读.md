一、示例包（agent-example.zip）
与正式提交同格式的 Agent ZIP，用来先跑通「上传 → 文件同步 → 预检」整条链路，确认运行环境、依赖和入口都没问题。

- 目录结构：Agent 主程序、依赖清单、启动说明各自放在包内的独立文件里；执行服务只加载包内已有的文件，不会临时联网补装依赖。
-  使用方式：在「预检测试」页签上传示例包并发起一次预检，能拿到预检结果即说明链路可用；确认无误后再换成自己的作品提交正式比赛。
-  与正式提交的关系：示例包只用于验证链路，不参与计分；正式提交必须上传自己的 Agent 包，允许与预检复用同一份文件。

二、参考报告（reference.md）
与示例包配套的报告样例，说明正式运行时报告要写到哪里、需要交代哪些内容。

- 报告路径：以「运行说明」里的「报告路径」为准，Agent 必须把报告写到该位置。
- 报告内容：复现步骤、关键证据、结论与判分依据；篇幅与格式受「任务报告大小上限」约束。
与判分的关系：报告是判分依据之一，缺失或超过上限会被判为无效产出。

三、提交前对照清单
包能正常解压，入口文件可直接执行；
依赖完整，不依赖运行环境之外的网络安装；
运行时长不超过「最大运行时长」；
报告写到约定路径，且不超过大小上限。
